## Technical Focus & Philosophy

I build native and cross-platform software designed around offline autonomy, defensive data persistence, and complete user privacy.

- **Local-First Reliability**: Applications prioritize local databases (SQLite) and device caches before interacting with remote services. Software must remain fully operable without network connectivity.
- **Privacy by Design**: Zero third-party behavioral analytics, trackers, or unsolicited telemetry. Data ownership belongs entirely to the user on their device.
- **Pragmatic Architecture**: Preference for clean, modular separation of UI, business state, and persistent storage layers over bloated dependency graphs.
